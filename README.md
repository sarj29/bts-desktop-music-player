# BTS Pixel Player

A retro-inspired BTS desktop music player built with Electron, React, and pixel art aesthetics.

Designed to feel like a collectible handheld gadget sitting on your desktop.

---

## Credits

Inspired by the original Cupid Music Player project by cupidbity.

Reimagined into a custom BTS-themed pixel desktop player.

---

## Preview

Layered pixel-art interface with:

* animated BTS chibis
* spinning vinyl
* draggable retro volume slider
* custom Electron window controls
* pixel-perfect rendering
* YouTube playlist support

---

## Features

### Visual System

* handcrafted pixel-art UI
* layered shell + overlay architecture
* animated sprite-style chibi system
* glowing interactive controls
* retro gadget aesthetic
* frameless desktop window

### Playback

* play / pause
* next / previous
* looping
* progress bar
* real-time timestamps
* vertical volume control
* rotating vinyl during playback
